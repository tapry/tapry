# 07 — Go-to-Market

## Positioning lines
- "Studio-quality remote recording you can own."
- "Riverside, but open source and self-hostable."
- "Every guest recorded locally — perfect audio even on bad Wi-Fi."

## Before launch (during build)
- Landing page + waitlist (cloud) + GitHub "watch" CTA.
- Build in public on X/LinkedIn: weekly progress clips (the recording/sync tech is very demo-able).
- Recruit **20 alpha podcasters**: r/podcasting, podcast Discords, small YouTube interview channels, university media labs.
- Collect quotes + a before/after demo (Zoom recording vs ours).

## Launch week (target: mid/late Jan 2027)
| Day | Action |
|---|---|
| Mon | Publish technical blog post |
| Tue | **Show HN** (morning US time) + X thread with demo video |
| Wed | r/selfhosted + r/opensource |

| Fri | Product Hunt |
| Next week | Submit to awesome-selfhosted, OpenAlternative, AlternativeTo, newsletters (Console.dev, Changelog, TLDR, selfh.st weekly) |

## Ongoing channels
- **SEO pages:** Riverside alternative, StreamYard alternative, Zencastr alternative, self-hosted podcast recorder, record remote interview locally.
- **YouTube:** setup tutorials (self-host in 5 min), "record a podcast free".
- **Partnerships:** podcast hosting platforms, course platforms, universities (pilot programs).
- **Creators:** free Studio plan for small interview podcasts that credit the tool.

## B2B motion (from month 6)
- Targets: EU universities, newsrooms, healthcare/legal training teams, companies with data-residency needs.
- Offer: business license or EU-hosted Business plan, DPA, security docs.

## Metrics
- GitHub stars, Docker pulls, active self-hosted instances (opt-in telemetry ping, anonymous).
- Cloud: sign-ups → first recording → second recording (activation) → paid.
- Recording success rate (must be ~100%), upload completion time after stop.
- Churn, MRR, AI add-on usage.
