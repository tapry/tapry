# 13 — Growth & Engagement Features

## 1. Growth loops (users bring users)

| Feature | Loop | Effort | Phase |
|---|---|---|---|
| **Guest → host** | End screen + recap email for every guest: their own clip/track + "Record your own — free". Each session reaches 1–7 new people | Low | **Launch** |
| **Share pages + clips** | Optional public page (player + transcript); free plan shows "Recorded with Tapry" | Low | v1.1 |
| **Embeddable player** | Audio/video + transcript embed on blogs/sites, link back | Medium | v1.2 |
| **Referral hours** | Invite someone → both get +5 h | Low | v1.1 |

## 2. Free tools, no sign-up (search traffic)

| Tool | Search intent | Phase |
|---|---|---|
| **Mic & camera test** | "test my mic online" | **Launch** |
| **Upload-speed check for recording** | "is my internet good enough to record a podcast" | **Launch** |
| **Free solo recorder** (one person, local file) | "free online voice/video recorder" | v1.1 |
| **Free transcript of an uploaded file** (limits) | "transcribe audio free" | v1.1 |
| **Interview consent form generator** | Researchers/podcasters | v1.1 |
| **GDPR data-flow template for research interviews** | Ethics applications (Tapry named in protocols) | v1.1 |
| **Show-notes generator** | Podcasters | v1.2 |

Each tool ends with: "Need to record guests? Try Tapry."

## 3. Retention (people come back)

| Feature | Why | Phase |
|---|---|---|
| **Shows & series** (seasons, episodes, recurring weekly studio) | Weekly habit | v1.1 |
| **Guest list / mini-CRM** (contacts, appearances, release forms, notes) | Hard to leave | v1.2 |
| **Run-of-show / episode planner** (segments, questions, timing) | Prep happens in Tapry; feeds the guide tracker | v1.1 |
| **Library search** | Value grows with every recording | v1.2 |
| **Team roles + transcript comments** | Team adoption | v1.1 |
| **Scheduling + reminders** (calendar invite with studio link, guest tech check link) | Fewer no-shows and failed sessions | v1.1 |
| **Usage stats** (episodes, hours, guests) | Sense of progress | v1.2 |

## 4. Widen the audience

| Feature | New users | Phase |
|---|---|---|
| **Solo mode** (screen + camera, Loom-style) | Teachers, creators, async updates | v1.2 |
| **Async interviews/testimonials** (questions → answers recorded alone) | Marketers, HR, researchers | v2 |
| **Multi-language UI** (FR, ES, AR, DE, PT) | Underserved non-English users | v1.1 |
| **Polished mobile-browser guest flow** | Guests anywhere | v1.1 |
| **Education mode** (class workspaces, free for students) | Future paying users; universities | v1.2 |

## 5. Switching & integrations

| Feature | Why | Phase |
|---|---|---|
| **Import from Zoom / Riverside / Google Drive** (transcribe + search old recordings) | Removes switching cost | v1.2 |
| **Auto-send** to Google Drive, Dropbox, YouTube, podcast hosts (Buzzsprout, Transistor) | Fits workflows | v1.2 |
| **Zapier / Make / n8n** | Directory exposure | v1.2 |
| **Slack/Discord bot** (`/tapry new studio`) | Starts in team chat | v2 |
| **Calendar integration** (Google/Outlook) | Every invite advertises Tapry | v1.1 |
| **API + webhooks** | Platforms build on Tapry | v1.2 |

## 6. Open-source ecosystem

| Feature | Why | Phase |
|---|---|---|
| **One-click self-host listings**: Umbrel, CasaOS, Unraid, Synology, Coolify, Railway, Dokploy | Self-hoster app stores = free distribution | Launch → v1.1 |
| **Plugin system** (exports, storage, AI models, integrations) | Community builds features; contributors + stars | v2 |
| **Public template gallery** (interview guides, show formats) | Shareable + SEO | v1.2 |

## Priorities
1. Guest → host loop (launch)
2. Free tools: mic test + upload check (launch), then solo recorder + transcript + consent form
3. Solo mode
4. Import + library search
5. Self-host app store listings
6. Multi-language UI

**Scope guard:** only #1 and the two simplest free tools ship with v1. The rest follow paid users.
